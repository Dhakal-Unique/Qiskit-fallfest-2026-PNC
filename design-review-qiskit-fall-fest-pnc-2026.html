🔴 Critical Issues

Critical Hero section has no minimum height — feels cramped on large screens
  • The hero only uses py-20 padding. On wide/tall screens it looks tiny compared to the content below.
  • Fix: Add min-h-[60vh] and flex flex-col justify-center to make it fill the viewport properly.
Critical About section is a wall of text — no visual breathing room
  • One long <p> tag with <br/><br/> for spacing. Looks like a raw text dump, not a designed section.
  • The daily schedule inside About duplicates the Schedule section below — confusing for visitors.
  • Fix: Split into proper paragraphs with margin. Remove the day-by-day list from About — it already exists in Schedule.
Critical No visual dividers between sections — page bleeds together
  • All sections share max-w-4xl mx-auto but Partners uses full-width bg-gray-800 — creates jarring width inconsistency.
  • On desktop, sections bleed into each other with no clear boundary at the edges.
  • Fix: Either make all sections full-width with centered inner content, or add a consistent border/divider between them.

🟡 High Priority Improvements

High WhyJoin uses a plain bullet list — lowest-effort section on the page
  • 7 plain <li> items with no visual treatment. Every other event page uses icon cards or a 2-column grid for this.
  • Fix: Use a 2-column grid of cards, each with a small emoji/icon, title, and one line of text.
High Speaker section has no session time or topic listed
  • The speaker card shows name, role, and bio — but doesn't say when the session is or what topic will be covered.
  • Visitors want to know: "What will I learn and when?"
  • Fix: Add session date (e.g. Nov 26), time, and topic below the bio.
High Navbar "Register" link is not visually distinct on desktop
  • On desktop, "Register" looks identical to "Contact" — same unstyled text. On mobile it's yellow (good!) but on desktop it blends in.
  • Fix: Style the desktop Register link as a small yellow pill button — same as the Hero CTA.
High Footer is too minimal — no links, no social icons
  • Just one line of copyright text. A professional event footer should have quick links and social media icons.
  • Fix: Add 3–4 quick nav links and social icons (email, LinkedIn, Facebook) in the footer.
